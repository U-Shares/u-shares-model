# Evidence — M0: The magnitudes are held (a design feature, not a gap)

**Claim (register):** *Any program magnitude* — reach, receipts, credit capacity, exact reserve — **held**,
not asserted.
**Status: `open`** — permanently, until a magnitude clears the stated gate.
**Warrant (proposed):** withholding every program magnitude until validated modeling and credentialed
sign-off is the discipline that keeps each other claim honest — publish what we expect to revise, never
what we'd have to retract.

## Why this row exists
Every quantitative claim in this register has a *structural* part (a mechanism, an ordering, a
convergence) and a *magnitude* part (a dollar figure, a per-person amount). The structures are published
and argued; **the magnitudes are deliberately not asserted** — not because none have been computed
(directional model outputs exist for all of them) but because none has cleared the two-stage gate this
row encodes:
1. **Validated modeling** — the model itself pre-registered, calibrated, and stress-reviewed (several of
   the directional models carry known calibration contests — see DS1, F6).
2. **Credentialed sign-off** — review by a credentialed economist (the "G3" gate), followed by explicit
   maintainer promotion.
A revised directional finding reads as science; a retracted headline number is permanent. The register's
`contested` rows demonstrate the mechanism working — challenges parked claims without any public number
having to be walked back.

## What is held (the inventory)
Reach per person by tier; net incremental receipts by scenario; credit capacity (S_max); the reserve size
(only "same order of magnitude" is claimed — F6); effect sizes for dispersion/retention (OQ-MD-004); the
true deductibility cost rate c. Where a number appears in a model file it is an **illustrative input or
directional output, labeled as such**, never a finding.

## Disconfirming test (register)
Validated modeling + credentialed-economist sign-off establishing or overturning a specific magnitude.
*(Note the asymmetry: this test "firing" is the program working as designed — a magnitude graduating out
of M0 through the gate, not a refutation.)*
