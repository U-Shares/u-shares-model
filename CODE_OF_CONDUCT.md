# Code of Conduct

This is a research repository whose purpose is adversarial scrutiny of its own claims. The standard is
simple: **attack the work, never the person.**

- Sharp, specific, well-sourced criticism of any claim, model, or assumption is welcome — it is the
  point of the repository.
- Personal attacks, harassment, discrimination, or bad-faith derailing are not tolerated, toward anyone.
- Political-values disagreements about the proposal are legitimate; route them as extensions/commentary
  (see `CONTRIBUTING.md`) and hold them to the same civility bar.
- The maintainer enforces this code (warnings, then blocking, for repeated violations) and is bound by it.

Report conduct concerns via a repository issue, or privately to the maintainer if the concern involves
another participant.
