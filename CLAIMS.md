# Claims Register

Every load-bearing claim, its status, and **the test that would disconfirm it.** One flat table (rubric guardrail 1). Depth — derivation, sources, sensitivity — lives one layer down in [`claims/evidence/<ID>.md`](claims/evidence/). This register is **maintainer-written, contributor-read**: no contribution path requires editing it; only the maintainer changes a status (see [`CALL_FOR_PAPERS.md`](CALL_FOR_PAPERS.md)).

**Statuses:** `supported` (evidence backs it; expected to be refined) · `contested` (a credible challenge has parked it — the honest middle state) · `open` (not yet answerable; needs evidence or expert review) · `retired` (falsified/withdrawn; kept visible in [`claims/retired/`](claims/retired/) with the falsifying artifact).

`supported` spans measured-to-directional findings — the disconfirming test states the strength of each claim.

**No settled magnitudes.** No program magnitude (reach per person, receipts, credit capacity, exact reserve) and no deficit-neutrality claim is asserted as established anywhere. Where a claim has a structural and a magnitude part, only the structure is registered; magnitudes are held (row **M0**).
